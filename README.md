# ArisenEngine

ArisenEngine 是一个开源的、面向学习与研究的自研渲染引擎，采用模块化架构，支持多平台构建与现代图形 API（如 Vulkan）。目标是打造一个兼具可扩展性与可读性的图形引擎，供开发者探索图形编程与引擎架构。

## 🧰 环境要求

| 组件          | 要求版本             |
| ------------- | -------------------- |
| CMake         | ≥ 3.29               |
| Vulkan SDK    | 已安装（建议最新版） |
| Visual Studio | 2022（支持 C++23）   |
| Windows SDK   | 10+                  |
| .NET SDK      | 9.0+                 |
| Python        | 3.0+                 |
